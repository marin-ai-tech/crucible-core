# Changelog

All notable changes to Crucible Core. Versions follow [Semantic Versioning](https://semver.org/) as described in the [versioning policy](VERSIONING.md); while the major version is 0, a minor version may change behavior.

## 0.1.0 — 2026-11-19

The first source release of the Crucible Core Rust workspace and its administrator client.

### Added

- Entity and component storage, prototype loading, and localization.
- Tile maps, 2D physics, fixed-tick simulation, and effects with conditions.
- Engine integration interfaces, player sessions, state replication, and test utilities.
- Administrator client for local process control, logs, SQLite tick history, and per-handler measurements.
