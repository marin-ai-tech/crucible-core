# Glossary

| Term | Meaning |
| --- | --- |
| ECS | Entity-component-system architecture. An entity identifies an object, components hold data, and systems process that data. |
| Prototype | A typed named data definition that can provide defaults and inherit from another prototype. |
| Grid | A map entity that stores tiles at integer coordinates and has its own transform. |
| Tick | One fixed step of the simulation. |
| Replication | Projection of world state and events into per-player data for a transport layer. |
| Source provenance | The upstream project, revision, path, and licensing record for adapted code. |
| Release tree | The exact set of versioned files inspected, tested, and approved for publication. |
